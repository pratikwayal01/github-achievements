# GitHub Achievements Checklist

Track GitHub achievement progress. Public because badge progress only counts in public repositories.

## Achievements & tiers

| Badge | Unlock | Bronze (I) | Silver (II) | Gold (III) |
|---|---|---|---|---|
| Pull Shark | Merged pull requests | 2 | 16 | 128 |
| Starstruck | Stars on a repo you own | 16 | 128 | 512 |
| Quickdraw | Close an issue/PR within 5 min of opening | 1 | — | — |
| Pair Extraordinaire | Co-authored commits | 2 | 8 | 16 |
| Galaxy Brain | Discussion answer marked by maintainer | 2 | 8 | 16 |
| YOLO | Merge a PR without review (public only) | 1 | — | — |
| Heart On Your Sleeve | ❤️ reaction on an issue/PR/discussion | 1 | — | — |
| Open Source Contributor | Merged PR in a project you don't own | 1 | — | — |
| Public Sponsor | Publicly sponsor an OSS project | 1 | — | — |

## Hard rules

- Activity on **private** repos never counts — badges require public work.
- Deleting or making a repo private removes badges earned from it.
- Badge progress shows on your profile only if the underlying repo is public.
- Sudden bursts from brand-new accounts trip GitHub's anti-abuse checks.
