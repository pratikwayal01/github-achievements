## Unlock conditions

- **Pull Shark** — PRs merged by you, any repo. Easy path: fixing typos in docs across OSS repos.
- **Starstruck** — stars on a repo you own. Organic: good README + demo GIF, post on HN/Reddit, add to awesome-lists.
- **Quickdraw** — open an issue or PR, close it yourself within 5 minutes.
- **Pair Extraordinaire** — commit with a `Co-authored-by: Name <email>` trailer. Email must exactly match the partner's verified GitHub email (use their `ID+login@users.noreply.github.com`).
- **Galaxy Brain** — answer a GitHub Discussion; a maintainer (or the discussion author) marks your answer with the ✅. Not available on issues/PRs — Discussions only.
- **YOLO** — merge a PR with no review (requires repo perms; public display is conditional).
- **Heart On Your Sleeve** — ❤️ reaction anywhere on GitHub.
- **Open Source Contributor** — merged PR in a repo you don't own.
- **Public Sponsor** — sponsor any OSS project publicly.

## Hard rules

- Activity on **private** repos never counts — badges require public work.
- Deleting or making a repo private removes badges earned from it.
- Badge progress shows on your profile only if the underlying repo is public.
- Sudden bursts from brand-new accounts trip GitHub's anti-abuse checks.
