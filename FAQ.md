# FAQ

## Do private-repo badges count?
No. Achievements only display for activity in public repositories. Private-repo activity stays hidden.

## Does deleting a repo revoke its badges?
Yes. Achievements earned from a repo are removed when the repo is deleted or made private.

## Is badge gaming risky?
GitHub bans *fake* activity: bot farms, bought stars, coordinated star bursts. Real commits with a co-author, real discussions, real merges are normal GitHub use — do those, don't fake the volume.

## Why is YOLO tier-hidden for some users?
YOLO is awarded for unreviewed merges but is only displayed publicly under certain conditions (it's hidden on repos with poor quality signals). It never shows for private repos.

## How do I check my own counts?
`./check.sh` — read-only queries via the GitHub API. No token write access needed, works with `gh auth login`.

## Which badges have no level system?
Quickdraw, YOLO, Heart On Your Sleeve, Open Source Contributor, Public Sponsor — single-tier. Pull Shark, Starstruck, Pair Extraordinaire, Galaxy Brain have I/II/III.
